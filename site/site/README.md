# Safestart UB nettside

React, TypeScript, Tailwind CSS og Vite. Konseptnettsiden bygger på merkevaren i `../bedrift/profil/` og vurderingen i `../research/2026-11-11-stitch-nettside-vurdering.md`.

```sh
cd site
npm ci
npm run selfcheck
npm run build
npm run dev
```

Åpne adressen Vite viser. Den lange telefonseksjonen bruker CSS `position: sticky`; rulling velger én av fem konseptskjermer. Prikker under teksten kan også brukes direkte. Innholdet er et konsept, ikke et dokumentert tjenesteløfte.
